# Idea Dump

A running junk drawer for anything Celestial Systems related — half-formed, contradictory,
too small to matter, or too big to ever build. Nothing here is a commitment. The point is
to have somewhere to throw a thought so it isn't lost, and somewhere to come back to when
stuck or bored and looking for a spark.

Add entries under whichever heading fits, or make a new one. Newest at the top of each
section. No format required — a sentence fragment is fine.

## Tech / Tooling

- In-game console / command input, Bethesda- or Minecraft-style, for debugging. Should plug into the existing debug-windows framework as an add-on window, but decoupled enough that it could live in a different presentation instead, as long as it has adequate input/output to the user. Needs both directions: inspecting/reading state and running commands.
-

## Wild / Long-shot

- Hook LLMs (Claude, ChatGPT, other remote/local models), TTS, and speech-to-text directly into the game. Inspired by SkyrimNet. Two angles:
  - Dev-facing: bring AI dev-assistant services (like this one) into the game itself for realtime inspection of live game state during development/testing, rather than working from outside.
  - Player-facing: use those same kinds of models to drive gamemaster-style behavior and NPC/actor intelligence in-game for more immersive, emergent character behavior.
- Related to the above: "take" an AI assistant around in-game like a companion, and point things out to it more free-form and naturally (rather than typing into a console) — a looser, more conversational way of showing it the project than a formal interface.
