# Third-Party Asset Baseline

This project uses licensed Unity Asset Store packages. Their source files are installed locally and intentionally excluded from Git.

| --- | --- | --- | --- |

| MapMagic 2 Bundle | 2.1.20 | `Assets/MapMagic` | Requires the compatibility patch below |

## MapMagic compatibility patch

MapMagic 2.1.20 uses the new Unity `EntityId` call beginning with Unity 6000.3, but its matching `AssetCreationEndAction` callback is conditionally enabled only for Unity 6000.5 or newer. Unity 6000.4 therefore reports ambiguous `ProjectWindowUtil.StartNameEditingIfProjectWindowExists` calls.

After importing MapMagic 2.1.20, run this from the project root:

```bash
git apply --ignore-space-change --ignore-whitespace Patches/MapMagic-2.1.20-Unity-6000.4.patch
```

If Unity reports that `Assets/MapMagic/Demo/Tutorial/LightingData.asset` is corrupt or was serialized by a newer Unity version, delete that baked tutorial lighting asset through Unity's Project window. It is not required by MapMagic and can be regenerated by rebaking the tutorial scene.

The patched vendor files remain ignored by Git. Reapply the patch after reinstalling or updating MapMagic, and reassess whether the patch is still needed when changing MapMagic versions.
